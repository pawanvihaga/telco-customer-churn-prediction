# Telco Customer Churn Prediction & Analytics

This is a machine learning-powered web application built with Streamlit to predict customer churn in the telecommunications industry.

## 🛠️ Tech Stack
- **Python**
- **Scikit-Learn, Pandas, NumPy, Joblib**
- **Streamlit**
- **Matplotlib, Seaborn**
- **Reportlab (PDF generation)**

## 📊 Key Features
1. **Secure Authentication System**
2. **Single Customer Prediction**
3. **Analytics & Visualizations**
4. **Bulk CSV Upload & Prediction**
5. **Professional PDF Report Generation**
